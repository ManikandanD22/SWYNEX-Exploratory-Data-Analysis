SWYNEX – Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a financial dataset as part of Task 2 of my internship at SWYNEX Technologies.

The objective is to understand the dataset, calculate descriptive statistics, explore numerical and categorical variables, visualize distributions, and identify useful patterns in the data.

## Objectives

- Understand the structure and characteristics of the dataset.
- Calculate descriptive statistics for numerical variables.
- Explore categorical variables and their frequency distributions.
- Visualize data using charts.
- Investigate relationships, patterns, and potential anomalies.
- Document at least five meaningful, data-driven insights.

## Dataset Description

The dataset contains financial and loan-related information, including customer demographics, income, loan details, credit scores, interest rates, EMI amounts, loan status, default status, and region.

The analysis uses the cleaned dataset prepared during Task 1.
